# TouchErase 测试教程

从零跑一遍，验证整个流程。分两条路：

- **一、没触摸屏**：用「注入」模拟接触，验证倍率/形状/峰值/手掌面积对齐（先跑这个最简单）
- **二、有触摸屏**：真机按手掌，走完整流程

---

## 0. 准备

- Windows 10/11 + .NET 10 SDK，或直接用发布出来的 `TouchErase.exe`
- 开发运行：项目根目录执行 `dotnet run`
- 启动后会自动弹「引导」，点「下一步」或「跳过引导」都行

---

## 一、没触摸屏：注入自测

> 目的：不依赖硬件，验证整条链路。

### 1. 看校准
看窗口顶部深色条，正常应显示 `来源: EDID … mm/px: 0.xxxx`。
- 没读到 → 在右侧「屏幕校准（EDID）」填屏幕对角线英寸（如 15.6），点「应用」。

### 2. 页① 描一圈手掌 → 得手掌面积 a
1. 切到「① 描摹手掌轮廓」页
2. 在白色区域**按住鼠标画一个圈**（模拟手掌轮廓）；底部状态栏会显示「已收集 N 点」
3. 点右侧「计算手掌面积（凸包+Shoelace）」
4. **预期**：右侧出现
   ```
   【② 手掌面积】
   描摹闭合曲线 ≈ XX.XX cm²
   凸包 ≈ XX.XX cm²
   ```
   **记下这个数 a（cm²）**，后面要用

> **更简单的方式（推荐）**：右侧「① 手掌尺寸」里直接填 **手宽 × 手长（cm）**（如 `12 × 18`）→ 点「应用尺寸」。
> 这样 a = 216 cm² 且**擦除区形状 = 12×18 的矩形**（朝向由输入决定，不看驱动），比描摹更准、更可控。

### 3. 页③ 注入模拟接触
1. 切到「③ 面积擦预览」页
2. `1 计数 = [0.5]` mm → 点「应用比例」
3. `模拟计数 = [200]` → 点「注入」
4. **预期**：黑区出现绿色擦除框；右侧 `EraserInfoText` 显示
   ```
   模式: 随压力变化（按越重越大）
   接触(中值滤波): 100.0 × 100.0 mm = 10000 mm²，倍率 自动 1.470 ×
   擦除区: 矩形 120.0 × 180.0 mm（面积 21600 mm²）
   ```
   （200 计数 × 0.5 = 100 mm，100×100 = 10000 mm²；若①用了 12×18 cm，则形状就是 **120×180 mm** 的矩形）

### 4. 验证「随压力变化」
把模拟计数改成别的再「注入」：

| 模拟计数 | 接触面积 | 擦除区面积（倍率 1.0） |
|---|---|---|
| 400 | 200×200 mm = 40000 mm² | 变大 → 40000 mm² |
| 100 | 50×50 mm = 2500 mm² | 变小 → 2500 mm² |

### 5. 验证「固定为手掌面积」
- 取消勾选「**随压力变化（关闭则固定为手掌面积）**」
- 随便再注入一个
- **预期**：擦除区面积**固定 = 第 2 步的 a**（cm² × 100 = mm²），不再随计数变

### 6. 验证「自动倍率（不用点，自动算）」
1. 勾回「随压力变化」
2. 确认「**自动倍率**」保持勾选（默认）；此时下面的滑块是**灰的**（只有手动倍率才用滑块）
3. 注入 200（接触面积 10000 mm²）
4. **预期**：**无需任何点击**，倍率标签直接变成 `倍率(自动) = 0.854 ×`（= √(a×100 / 10000)），擦除区面积 ≈ a
   - 例：a = 73 cm² → √(7300/10000) ≈ 0.854 → 擦除区 ≈ 7300 mm²
5. 想手动试：取消勾选「自动倍率」→ 滑块变可用，拖动滑块擦除区随倍率平方变化

### 7. 验证形状
点「正圆（等面积）」→ 擦除区变圆，**面积不变**（等面积圆）。

## 二、有触摸屏：真机流程

1. 同「一、1」完成校准
2. 同「一、2」描手掌 → 记下面积 a
3. **页② 手掌接触面积**：切到「② 手掌接触面积」页，把**整只手（含手指）**按在黑区上
   - **预期**：右侧出现两行
     ```
     当前      41.4 × 54.8 mm = 2269 mm²
     本次峰值  41.9 × 54.9 mm = 2300 mm²
     ```
     松开后「本次峰值」保留，直到下一次按下才重置
   - 记下峰值 b（mm²）
4. **页③ 面积擦预览**：切到第③页，「接触来源」保持默认「**自适应（自动锁定）**」，把手按在黑区
   - **预期**：`SourceInfoText` 显示 `自适应：已锁定 原始HID(设备上报)`（或锁到你设备上可用的那一路）
   - 绿框大小 = 接触面积 × 倍率，**按越重越大**
5. **设备只报「计数」没毫米单位时**（HID 诊断里 `Width(0x48)=True` 但 `PhysicalMax=0`）：
   - 点「**标定 HID 计数→mm（用①的手掌面积）**」
   - 需要先在①量过面积、并在③按过一次手掌（采到峰值计数）
   - 标定后原始 HID 就能给出毫米
6. 确认「**自动倍率**」保持勾选（默认）→ 按下时擦除区 ≈ 手掌面积 a（无需手动设置；想手动就取消勾选，用下面的滑块）

---

## 三、查日志 / HID 诊断

- 右侧「日志」：勾「记录到日志文件」
- 点「**HID 触摸诊断（写日志）**」→ 日志里会列出每个 HID 设备是否声明 `Width(0x48) / Height(0x49)`
- 点「打开日志文件夹」看 `logs\`（含逐帧 HID Bounds、接触来源、擦除区面积）

---

## 四、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 页②/③ 按下去没反应、显示「未读到」 | 设备没上报接触尺寸（鼠标，或该驱动不报 Width/Height）。改用注入自测，或看 HID 诊断 |
| 面积忽大忽小 | 看是否"按越重越大"属正常；查 `SourceInfoText` 是否已稳定锁定 |
| 竖尺对不上 | 「EDID 尺寸推算方式」切「按宽推竖（方形像素）」 |
| 固定手掌面积模式没反应 | 还没在①量出手掌面积——右侧会提示先去①描摹 |

## 五、校准向导（独立程序 TouchErase.Calibrator）

`dotnet run --project Calibrator/TouchErase.Calibrator.csproj`

7 步，每步只问一件事：

| 步 | 做什么 | 预期 |
|---|---|---|
| 1 | 看横向 10cm 线是否准（每 1mm 一格，拿尺子量） | 选「准/不准」 |
| 2 | 看纵向 10cm | 选「准/不准」 |
| 3 | 推算方式（自动由前两步得出） | 都准=各按各；只横准=按宽推竖；只竖准=按竖推宽；**都判不准或 EDID 读失败** → 才露出「手动标定」面板（画 10cm + 微调滑块，或填对角线） |
| 4 | 手掌尺寸：左描摹 / 右填宽高（默认 12×18） | 顶部信息栏出现手掌面积与长宽比 |
| 5 | 用整只手按一下 → 「记录手掌」（可多按几次，取中值） | 实时/峰值与压感；**压感是否可用看顶部"压感"行**（恒定=设备不给真压感） |
| 6 | 用一根手指按一下 → 「记录手指」 | 同上 |
| 7 | **面积擦预览**（整套 = 主程序第③页） | 按下去实时画出等大擦除区；无硬件时点「应用比例」+「注入」自测 |

**第 7 步自测（无触摸屏）**：`1 计数 = 0.5` → 点「应用比例」→ `模拟计数 = 200` → 点「注入」→ 右侧应显示
```
模式: 随压力变化（按越重越大）
接触(中值滤波): 100.0000 × 100.0000 mm = 10000.00 mm²，倍率 自动 1.469694 × 微调 ×1.000000 → 生效 1.469694 ×
擦除区: 矩形 … （面积 …）
```
（200 计数 × 0.5 = 100 mm）

**三个 GroupBox（自动 + 微调滑块）**：
- **倍率**：自动计算；拖动微调滑块 → `生效倍率 = 自动 × 微调`，擦除区随之变化（微调 1.20 → 生效 = 自动 × 1.2，面积 ×1.44）
- **面积阈值 / 压感阈值**：第 5、6 步记录过按压后自动得出；未记录时显示「自动：待标定」；拖动滑块微调

最后「保存结果到文件」→ `calibration.json`（含自动值与微调后的生效值）。
